# Pescadores de Cristo

## Sistema de Gestão da Associação Beneficente Pescadores de Cristo

### 1. Sobre o projeto

O Pescadores de Cristo é um sistema web desenvolvido como projeto acadêmico da disciplina Projeto de Software, do curso de Análise e Desenvolvimento de Sistemas.

A aplicação tem como objetivo facilitar o gerenciamento de beneficiários, cursos, inscrições e participações da Associação Beneficente Pescadores de Cristo, contribuindo para a organização das atividades e o acompanhamento das pessoas atendidas pela instituição.

### 2. Objetivo

Desenvolver uma solução digital que centralize informações, facilite o gerenciamento de cadastros e contribua para melhorar os processos administrativos da associação.

### 3. Tecnologias utilizadas

- Python
- Django
- SQLite
- HTML
- CSS
- Git e GitHub
- GitHub Actions

### 4. Estrutura do projeto

- `beneficiarios/` – Aplicação responsável pelas funcionalidades relacionadas aos beneficiários.
- `config/` – Configurações principais do projeto Django.
- `.github/workflows/` – Configurações de integração contínua.
- `manage.py` – Arquivo de gerenciamento da aplicação.
- `requirements.txt` – Dependências do projeto.
- `README.md` – Documentação do projeto.

### 5. Funcionalidades previstas

- Gerenciamento de beneficiários.
- Organização de cursos.
- Controle de inscrições.
- Acompanhamento de participações.
- Centralização das informações da associação.

### 6. Instalação e execução

Para executar o projeto localmente:

1. Clone o repositório.
2. Crie e ative um ambiente virtual Python.
3. Instale as dependências utilizando `pip install -r requirements.txt`.
4. Execute as migrações com `python manage.py migrate`.
5. Inicie o servidor com `python manage.py runserver`.

A aplicação poderá ser acessada pelo endereço local `http://127.0.0.1:8000/`.

### 7. Impacto social

O projeto busca contribuir para a organização das atividades da Associação Beneficente Pescadores de Cristo, apoiando a gestão das informações e facilitando o acompanhamento dos beneficiários e das ações desenvolvidas pela comunidade.

### 8. Finalidade acadêmica

Projeto desenvolvido para a disciplina Projeto de Software, como parte das atividades práticas do curso de Análise e Desenvolvimento de Sistemas.
